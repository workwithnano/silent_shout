# Screenshots

Taken by the UI tests on the pool simulator (iPhone 17 Pro, iOS 27), exported from the result
bundle, turned upright and scaled so the long side is 1400 px. All of them are from the
phase 6 run, so they show the app as it is now.

Options:

- `options.png`: the Options screen with the original defaults (Pencil, Notecard, Scale your note).
- `options-help.png`: the same with help on, the three bubbles beside the option art.
- `options-camera.png`: the background carousel on Cardboard, with the camera disc in its right margin.
- `options-camera-choices.png`: the "Background Photo" choices by the camera disc.
- `options-camera-photo.png`: a photo in use: textures dimmed, no page dot lit, the disc showing the photo.

Editing:

- `editing-short.png`: Editing with "Hi Mom!" in Pencil on the notecard preview, keyboard up.
- `editing-long.png`: a long message fitted small into the preview.
- `editing-photo.png`: the preview drawn on a photo (the UI tests' blue fixture picture).

Shout:

- `shout-fit-short.png`: fit mode, Pencil on notecard, "Hi Mom!".
- `shout-fit-long.png`: fit mode, Dry-Erase on whiteboard, a long message on four lines.
- `shout-fit-keyboard.png`: fit mode, Keyboard (Helvetica) on cardboard, "Gate B12".
- `shout-scroll.png`: scroll mode, the marquee a moment after it starts, Keyboard on cardboard.
- `shout-toolbar.png`: the toolbar over a scrolling Dry-Erase shout on notecard.
- `shout-export-button.png`: the toolbar over a fit-mode shout, with the export button at the right.
- `shout-export-sheet.png`: the "Export Shout" sheet (the simulator cannot send messages, so "Send in iMessage" is absent).
- `shout-photo.png`: a fit-mode shout on a photo, the ink multiplied onto it.
