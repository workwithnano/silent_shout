## Notes for the next phases

- **Layout.** `SilentShout/` (app), `SilentShoutTests/` (Swift Testing, hosted in the app), `SilentShoutUITests/` (XCUITest) are file-system-synchronized groups: add files on disk, never edit pbxproj file lists. `SilentShout/Info.plist` is excluded from resources by an exception set; it holds only `UIAppFonts` and `UILaunchScreen`, the rest is generated from build settings (`INFOPLIST_KEY_*`).
- **Orientations.** The app target allows portrait and both landscapes (`INFOPLIST_KEY_UISupportedInterfaceOrientations_iPhone`); phases 2 to 4 restrict per screen.
- **Model.** `ShoutSettings` (`Model/ShoutSettings.swift`) writes to UserDefaults on every assignment. Phase 3 should keep the field's text in local state and assign `settings.text` on each screen change (ruling 9), not on every keystroke. The lettering setting is the `sizing` property (key `lettering`). Out-of-range stored values clamp to the nearest option (a stored lettering 2 reads as scroll); SPEC section 4 records this.
- **Names.** `ShoutFont.fontName` (`lateron`, `Kristi`, `Helvetica`), `.ink` (`InkColor`, `.color` / `.uiColor`), `.carouselImageName`; `ShoutTexture.shoutImageName` / `.previewImageName` / `.carouselImageName`, `ShoutTexture.cameraCarouselImageName`; `ShoutSizing.frameImageNames` (40 names) and `animationDuration` (5 s); `ChromeImage` holds every button, help bubble and toolbar asset name. Asset names are the original file names without extension.
- **Art sizes.** The preview textures' @2x files are 639x451 px (half a point short) and `bkgrnd_main@2x` is 640x921; size those by frame. Back2/doubleback/share are 38x38 pt art (ruling 7); the Editing `btns_back` is 33x33.
- **Placeholder.** Removed in phase 2. Font and image loading is still asserted by `BundleResourceTests`.
- **Navigation (phase 2).** `Navigation/AppNavigation.swift`: `RootView` owns a `NavigationStack(path:)` driven by the `@Observable` `AppNavigation` in the environment (`showEditing()`, `pop()`, `popToOptions()` for phase 4's double-back). `AppRoute.editing` maps to `EditingView` (phase 3). Screens hide the system nav bar (`.toolbar(.hidden, for: .navigationBar)`), so the swipe-back gesture is off; the screen's own back button pops.
- **Orientation (phase 2).** `OrientationLock.set(_:)` (same file) plus `AppDelegate.supportedInterfaceOrientationsFor` returns `OrientationLock.mask`, default `.portrait`; Options and the stub call `.set(.portrait)` on appear. Phase 4 sets `.landscape` for the shout and back to `.portrait` on leaving.
- **Options views (phase 2).** `Views/OptionsView.swift` (screen, `HelpBubble`, `MainBackground` with the mirrored tile, `OptionsAccessibilityID`), `Views/OptionCarousel.swift` (generic paged carousel + `PageDots`; its `trailing:` slot is laid out after the last page and is never a page: phase 5 puts the camera entry there), `Views/SizingAnimationView.swift`, `Views/ImageButtonStyle.swift` (UP/DOWN/selected art buttons; reuse for Editing and Shout buttons). Pure geometry and logic in `Layout/OptionsLayout.swift`: `OptionsLayout`, `CarouselPaging.page(forOffset:pageWidth:count:)`, `SizingAnimation.frameIndex(elapsed:)`, unit-tested in `OptionsLayoutTests.swift` at 320, 375, 390, 402 and 440 pt widths. `MainBackground` is the Editing background too.
- **Carousel persistence.** Writes only while the user drives the scroll (scroll phase interacting/decelerating, then a final write at idle), so the initial positioning never overwrites the stored value. VoiceOver adjusts with swipe up/down (`accessibilityAdjustableAction`); XCUITest on iOS has no increment/decrement, so that path has no UI test.
- **UI test helpers.** `SilentShoutUITests/OptionsScreen.swift`: `XCUIApplication.optionsApp(reset:)` adds `-UITestResetSettings` (handled in `SilentShoutApp.init`, DEBUG only, via `ShoutSettings.resetStoredOptions`), and `OptionsScreen` holds the queries (`carousel("font"|"texture"|"lettering")`, `value(of:)`, `bubble(_:)`, `helpButton`, `nextButton`, `waitForValue`). Accessibility ids: `options.carousel.<key>`, `options.help`, `options.next`, `options.help.bubble.<key>`. `testScreenshots` attaches `options` and `options-help`; export with `xcrun xcresulttool export attachments --path <xcresult> --output-path <dir>`.
- **Unit tests also build the UI test target** (the scheme builds all targets for `make test`), so UI test compile errors and warnings break `make test`.
- **Simulator.** The pool device is an iPhone 17 Pro on iOS 27.0 (deployment target is 26.0). A cold `make test-ui` took under a minute here. Result bundles land in `build/Logs/Test/`.
- **Sound.** PLAN phase 1 lists the sound file, but SPEC marks `swish.caf` as never played and the phase 1 brief said not to bundle it; it is not bundled (a unit test checks).
- **Version.** `MARKETING_VERSION` 2.0, build 1: a placeholder, like the bundle id.
- **Shout entry point (phase 3).** `AppNavigation.startShout()` is the only way in: it sets `isShouting` (refused, returning false, while a shout is up or still dissolving away, `isShoutOnScreen`, or when Editing is not the top screen). `RootView`'s background holds `ShoutPresenter` (`Navigation/ShoutPresenter.swift`), which presents a `ShoutHostingController` (UIKit, `.fullScreen`, `.crossDissolve`, status bar hidden) with `ShoutView` while `isShouting` is true, and dismisses it when `endShout()` clears it; it reports `shoutPresentationDidChange(onScreen:)` as it presents and when the dismissal completes. `ShoutView` (`Views/ShoutView.swift`) is a marked STUB: phase 4 replaces its body and keeps the type name. It gets `ShoutSettings` and `AppNavigation` through the environment (passed explicitly by `RootView`, since it lives in its own hosting controller). Its stub ids: `shout.stub`, `shout.text`, `shout.back` (calls `endShout()`). Phase 4: give `ShoutHostingController` its landscape orientations (it is a separate view controller, so Editing underneath can stay portrait) and add double-back as `endShout()` plus `popToOptions()`.
- **Orientation hook (phase 3).** `RootView` is the one place `UIDevice.orientationDidChangeNotification` enters the app (generation is switched on in `AppDelegate`); it calls `AppNavigation.deviceOrientationDidChange(_:)`, which stores `deviceOrientation`. `ShoutOrientationRule.startsShout` (either landscape) and `.leavesShout` (portrait) say what counts. Editing reacts with `.onChange(of: navigation.deviceOrientation)`; phase 4's shout should do the same with `leavesShout` (back to Editing). The interface stays portrait through `OrientationLock` while this happens.
- **TextFitter (phase 3).** `Layout/TextFitter.swift`: `TextFitter(boxWidth:boxHeight:maxSize:minSize:step:)`, with `.preview` (300x206, 200 to 12 by 2) and `.shout` (420x280, 360 to 12 by 2, for phase 4). `fontSize(for: text, fontName:)` measures with `wrappedHeight(of:font:width:)`; `fontSize(heightAt:)` is the bare rule for a custom measurer; `candidateSizes` lists the sizes tried. Empty text returns `maxSize`; nothing fitting returns `minSize`. Results are reference-box points: multiply by the canvas scale when drawing (ruling 5). `PreviewLabel` in `Views/EditingView.swift` is a `UILabel` wrapper (centred, word wrap, clipped) that phase 4 can reuse for the shout's fit text before compositing.
- **Editing (phase 3).** `Views/EditingView.swift` (`EditingView`, `PreviewCard`, `PreviewLabel`, `TextBar`, `EditingAccessibilityID`), `Views/ShoutTextField.swift` (`UITextField` wrapper; `FocusingTextField` takes first responder whenever `wantsFocus` is set and it is in a window, which is how the keyboard comes back after the shout), `Layout/EditingLayout.swift` (bar, card and field frames from the safe area above the keyboard; unit-tested at 320, 375, 402 and 440 pt). The field's text is local (`draft`) and written to `settings.text` on back, on starting the shout, and when the app leaves the foreground. Returning from the shout reloads `draft` from `settings.text` (the original re-ran its setup).
- **UI test helpers (phase 3).** `SilentShoutUITests/EditingScreen.swift`: `EditingScreen(app:)` with `open()` (Next from a fresh launch, then waits for keyboard focus), `textField`, `backButton`, `preview` (its accessibility value is the previewed text), `clearButton`, `shoutStub`, `shoutText`, `shoutBack`, and state waits `waitForFocus()` (`hasKeyboardFocus`), `waitForPreview(_:)`, `waitForField(_:)`, `waitUntilGone(_:)`. Ids: `editing.back`, `editing.textField`, `editing.preview`. The Done key is `typeText("\n")`. Rotation tests set `XCUIDevice.shared.orientation` and reset it to portrait in a teardown block. `testScreenshots` attaches `editing-short` and `editing-long`; screenshots in `docs/rewrite/screenshots/` are downscaled with `sips -Z 1400`.
